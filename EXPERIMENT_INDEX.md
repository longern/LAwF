## Supporting Diagnostics

- Annotation audit summary: `experiments/annotation_audit_summary.py`; outputs `artifacts/annotation_audit_v1/`.
- Annotation contract regression: `experiments/annotation_contract_regression.py`; outputs `artifacts/annotation_contract_regression_v1.json` and `artifacts/annotation_contract_regression_v2.json`.

- Qwen3.5-9B generation probe diagnostic: `experiments/qwen35_9b_generation_probe_eval.py`; outputs `artifacts/qwen35_9b_generation_probe_eval_v1/` and checks whether candidate Pareto adapters actually generate the target atoms under direct, KB-record, and reverse probes.
- Qwen3.5-9B LAwF alpha generation diagnostic: `experiments/qwen35_9b_generation_probe_eval.py`; outputs `artifacts/qwen35_9b_lawf_alpha_generation_probe_v1/` for the best alpha-sweep LAwF adapters.
- Scaled sparse-stream Pareto diagnostic: `experiments/scaled_sparse_pareto_sweep.py`; outputs `artifacts/scaled_sparse_pareto_sweep_v1/`.
- Superseded Qwen3.5-9B beta-only Pareto diagnostic: `experiments/qwen35_9b_pareto_sweep.py`; outputs `artifacts/qwen35_9b_pareto_sweep_v1/`. The paper-facing Qwen3.5-9B calibration is now the token-normalized alpha/beta sweep in Section 4.3.
- Earlier boundary coverage sweep diagnostic: `experiments/boundary_coverage_sweep.py`; outputs `artifacts/boundary_coverage_sweep_v1/`. The paper-facing rerun is Appendix A.14.
- KnowEdit-ZsRE LAwF acquisition-heavy calibration probes: `experiments/knowedit_zsre_lawf_benchmark.py`; outputs `artifacts/knowedit_zsre_lawf_fulltarget_a4b0p5_v1/`, `artifacts/knowedit_zsre_lawf_fulltarget_a8b0p25_v1/`, `artifacts/knowedit_zsre_lawf_probability_floor_p090_a2_b05_v1/`, `artifacts/knowedit_zsre_lawf_probability_floor_p095_a2_b05_v1/`, and `artifacts/knowedit_zsre_lawf_probability_floor_p095_a4_b025_v1/`. These acquisition-heavy LAwF variants were weaker than the unit-weight probability-floor frontier and are not summarized in the paper table.
- Qwen3-0.6B ROME KnowEdit-ZsRE pilot: `experiments/rome_knowedit_zsre_baseline.py`; outputs `artifacts/rome_knowedit_zsre_128_qwen06_v1/`. The paper-facing model-editing baseline is the same-subset Qwen3.5-9B run in Appendix A.18.
- Sequential update diagnostic: `experiments/sequential_update_diagnostic.py`; outputs `artifacts/sequential_update_diagnostic_v1/`.
- Superseded cheap QA, MCQ, and SFT-overfit diagnostics were run on the old formal/material trace and are not paper-facing evidence for the current draft.
